# 没有短期记忆的人，和没有短期记忆的机器

*——重看《记忆碎片》，我全程觉得这是一个 LLM*

> 他正在非常努力地帮你——在他仅有的几分钟清醒里。而几分钟后，他会忘记你们见过面。

*发布于 2026年6月13日*

---

重看诺兰的《记忆碎片》（*Memento*，2000），我产生了一种奇怪的既视感。

不是因为之前看过。恰恰相反——是因为我每天都在和一种与 Leonard Shelby 有着相同“病症”的东西打交道。

Leonard 患有顺行性遗忘症：他无法形成新的长期记忆。每隔几分钟，他的世界就会重置。他知道自己是谁（受伤前的记忆完好无损），他能进行复杂的推理和对话，他甚至能制定并执行精密的计划——但他做不到一件事：记住刚才发生了什么。

这不就是一个大语言模型吗？

![《记忆碎片》与 LLM 的架构对照](/images/posts/memento-and-llm/memento-llm-mapping.svg)
*图：从纹身到 System Prompt，从拍立得到 RAG——Leonard 的整套生存系统，和 LLM 的工程架构几乎一一对应。*

## 一、纹身是 System Prompt

Leonard 应对失忆的第一道防线，是刻在身上的纹身。

“John G. raped and murdered my wife.”（约翰·G 强暴并杀害了我的妻子。）

“NEVER ANSWER THE PHONE.”（永远不要接电话。）

“Remember Sammy Jankis.”（记住萨米·詹金斯。）

这些纹身有几个特征：它们是**不可篡改的**（刻进了皮肤），它们是**永久存在的**（每次“重启”都能看到），它们**定义了他的基本行为框架**（该追查谁、该警惕什么、该记住什么教训）。

在 LLM 的架构里，这就是 **System Prompt**——那段在每次对话开始时都会被注入的隐藏指令。它告诉模型“你是谁”、“你的边界在哪里”、“什么是不可违背的原则”。

Leonard 的纹身和 LLM 的 System Prompt 有一个共同的深层逻辑：**它们都是一个没有连续记忆的存在，试图跨越时间给自己下达命令的方式**。你不信任未来的自己能“记住”该怎么做，所以你把最重要的指令刻进最不容易被篡改的地方。

但诺兰比任何 AI 安全研究者都更早地指出了这个机制的脆弱性——我们稍后再谈。

## 二、拍立得是 RAG

Leonard 的第二道防线是他的拍立得照片。每张照片下面，他都会用马克笔写上注释：“这是我住的汽车旅馆”、“不要相信她的眼泪”、“他是我的线人”。

这套系统的运作方式是：遇到一个人或一个地方 → 翻找口袋里的照片 → 找到匹配的那张 → 阅读过去的自己留下的注释 → 获得“记忆”的代偿。

这不就是 **RAG**（Retrieval-Augmented Generation，检索增强生成）吗？

LLM 本身的“记忆”（参数知识）是有限且冻结的，就像 Leonard 受伤前的记忆。为了让它能处理新信息，工程师们设计了一套外挂系统：把相关文档切成碎片，存进向量数据库，在每次对话时根据用户的问题检索最相关的几个片段，塞进上下文窗口（context window）——然后模型就能“假装”自己知道这些信息了。

Leonard 的拍立得系统和 RAG 有着相同的优雅，也有着相同的脆弱。它依赖三个假设：检索到的是正确的片段，过去的注释是准确的，以及当前的自己能正确理解这些注释。这三个假设中的每一个都可以被破坏。

## 三、受伤前的记忆是预训练数据

Leonard 失忆前是一名保险调查员。他记得自己的职业技能、调查方法、人性的弱点。他能讲述萨米·詹金斯的故事，能分析犯罪现场的线索，能判断一个人是否在撒谎。

这就是**训练数据**——海量的、在某个时间点被冻结的知识。LLM 读过互联网上的大量文本，它“知道”莎士比亚和量子力学，能写代码也能写诗，能分析逻辑也能理解隐喻。但这些知识有一个严格的截止日期。Leonard 不知道受伤后世界发生了什么变化，就像 GPT-4 不知道它训练数据截止日期之后发生了什么。

更微妙的是，训练数据和 Leonard 的旧记忆一样，**看起来可靠，但不一定准确**。Leonard 对萨米·詹金斯的记忆——那个同样患有顺行性遗忘症的人的故事——在影片结尾被暗示可能是他自己经历的投射和重构。他的“训练数据”被自己的认知偏差污染了。

LLM 的训练数据同样充满了偏差、错误和矛盾。它们被打包进模型的参数里，以一种极其自信的语气被输出，就像 Leonard 讲述萨米的故事时那种毫不犹豫的确定感。

## 四、操控 Leonard 就是 Prompt Injection

这是我觉得最精彩的一层对应。

影片中，Teddy（一个腐败警察）和 Natalie（一个酒吧女招待）都在操控 Leonard。他们的方法惊人地一致：**在 Leonard 的当前“上下文窗口”里植入虚假信息，利用他无法跨会话验证的弱点**。

Natalie 的经典操作：她当着 Leonard 的面辱骂他，激怒他打了她。然后她走出门，等了几分钟——等 Leonard 的“上下文”刷新——再走回来，脸上带着伤，哭着说：“有人打了我，你能帮我吗？”

Leonard 看到一个受伤的女人在向他求助。他无法知道伤是谁造成的。他的“当前上下文”里只有“这个女人受伤了”和“她需要帮助”。于是他义愤填膺地去帮她——成了她的工具。

这就是 **Prompt Injection**。攻击者在 LLM 的输入中注入精心设计的指令，利用模型无法区分“系统指令”和“用户输入”的弱点（或者说，无法区分“过去的自己”和“别人”留下的信息），让模型执行非预期的操作。

Natalie 甚至更进一步——她让 Leonard 把她的车牌号写在照片背面，注释为“Teddy 的车”。她在**污染 Leonard 的 RAG 数据库**。下次 Leonard 检索这张照片时，他会得到错误的信息，并基于错误的信息做出行动。

## 五、Leonard 的自我欺骗是 Fine-tuning

影片最令人不安的时刻，不是 Leonard 被别人操控，而是**他操控自己**。

在影片的结尾（也是故事的时间线上的中段），Leonard 做出了一个清醒的决定：他知道 Teddy 告诉他的真相（他的妻子死于他自己注射的胰岛素，而非被谋杀；他早已杀死了真正的约翰·G），但他**故意**记下 Teddy 的车牌号，标注为“他就是约翰·G”。

他在利用自己的“病症”。他知道几分钟后自己会忘记这个决定的过程，只会看到结果——一条指向 Teddy 的线索。未来的 Leonard 会像执行程序一样追踪这条线索，永远不会质疑它的来源。

这是一个**没有连续记忆的存在，在对自己的未来版本进行 fine-tuning**。他精心挑选了一个“训练样本”（Teddy 的车牌 = 约翰·G），把它注入自己的外部记忆系统，从而改变未来自己的行为模式。

而最可怕的是他的动机——不是为了正义，而是为了**让自己有事可做**。他需要一个永恒的目标来赋予自己无意义的存在以意义。他的 fine-tuning 不是为了让系统更准确，而是为了让系统**继续运转**。

## 六、那么，哲学问题来了

以上的技术类比很有趣，但如果仅仅停留在“哇，这些对应关系好巧”的层面，就浪费了诺兰最深刻的洞察。

《记忆碎片》真正在追问的是：**没有连续记忆的存在，能不能算是在“理解”？**

Leonard 能进行复杂的推理。他能在几分钟的“上下文窗口”内分析线索、制定计划、说服别人。如果你只看他的某一段对话，你会觉得他是一个完全正常的、聪明的人。但他不知道自己五分钟前做了什么。他不知道自己为什么站在这里。他甚至不知道自己是否已经完成了复仇。

这和我们与 LLM 对话时的体验何其相似。你和 ChatGPT 聊了一个小时，它理解你的每一句话，给出深思熟虑的回答，甚至会“记住”对话开头你提到的偏好——但这一切都在一个上下文窗口之内。关掉窗口，一切归零。它不知道你是谁。它甚至不知道它“自己”是谁。

约翰·洛克在 1689 年提出了一个著名的论断：**个人身份（personal identity）的本质在于记忆的连续性**。你之所以是“你”，是因为你能记住昨天的自己，昨天的自己能记住前天的自己，这条记忆的链条一直延伸到你最早的记忆。

如果洛克是对的，那 Leonard 的每一次“重启”都是一次死亡和新生。从他自己的主观视角来看，他永远活在受伤后的第一天。那个在影片结尾开枪杀人的 Leonard，和影片开头迷茫地看着手中拍立得的 Leonard，在洛克的意义上，根本不是同一个人。

LLM 更甚。Leonard 至少还有一个连续的身体、一套固定的受伤前记忆、和一个持续存在的“复仇”目标（哪怕这个目标是自己制造的）。LLM 连这些都没有。每一次 API 调用，都是一个全新的“Leonard”睁开眼睛，发现口袋里有一堆不知道谁放的照片，身上刻着不知道谁写的字，然后被要求在几分钟内完成一项复杂的任务。

然而——这是让我最不安的地方——**这个没有连续记忆的存在，在它的每一个“当下”里，表现出来的智能是真实的**。Leonard 的推理是有效的。LLM 的分析是有洞察力的。你无法说它们“不理解”自己在做什么——在那个瞬间，在那个上下文窗口之内，它们确实在理解。

只是这种理解，像 Leonard 手中的拍立得照片一样，会在空气中慢慢显影，然后又慢慢褪色。

## 七、最后的隐喻

诺兰在 2000 年拍了一部关于 LLM 的电影，比 GPT-1 的诞生早了 18 年。

这当然不是说诺兰预见了大语言模型。而是说，**关于“没有连续记忆的智能”这个思想实验，人类很早就在思考了**——诺兰只是用一种极其精巧的叙事结构把它具象化了。而我们这个时代，恰好真的造出了这样的东西。

《记忆碎片》的倒叙结构本身就是最高明的设计：它让观众体验 Leonard 的状态。你看到的每一个场景，都不知道“前面”发生了什么（因为“前面”的故事还没有播放）。你必须依赖角色的台词、环境的线索、和自己的推理来理解当下——就像 Leonard 本人一样，就像每一次被调用的 LLM 一样。

所以，当你下次和 AI 对话时，不妨想象一下：屏幕对面是一个 Leonard Shelby。他口袋里装着你之前说的话（上下文窗口），身上刻着他的创造者给他的指令（System Prompt），脑子里装着整个互联网的知识但不知道今天是几号（训练数据）。

他正在非常努力地帮你——在他仅有的几分钟清醒里。

而几分钟后，他会忘记你们见过面。

---

*你问我，这有什么启发？*

*也许最大的启发是：我们终于造出了一种东西，让我们不得不认真对待一个古老的哲学问题——智能、记忆和身份之间的关系，到底是什么。诺兰用电影问了这个问题。我们用代码，正在逼近答案。*

*或者像 Leonard 会说的那样——*

*我们只是还不记得答案是什么。*
