形外是一个可持续扩展的交互与视觉实验库。13 个展区、183 件展品，每一件都拥有独立实现与实验参数。

01 / 体验

在卡片中直接操作，进入实验台放大、调色、暂停与重播。

02 / 拆解

核心代码页展示实际运行的效果函数。Markdown 手册包含逐项原理、源码与注意事项。

03 / 延伸

统一目录驱动导航、计数和文档。按分类添加一个效果函数，再运行构建即可扩充展馆。

纯本地运行，无外部字体与脚本。收藏及主题仅保存在本机浏览器；密码演示不存储任何输入。
